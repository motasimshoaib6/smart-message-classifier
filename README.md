
# Smart Message Classifier

A beginner-friendly machine learning project that classifies
text messages as Spam or Not Spam.

## Project Goals

- Prepare and process text data.
- Extract numerical features using TF-IDF.
- Implement a Multinomial Naive Bayes classifier.
- Evaluate model performance.
- Learn Git and GitHub through practical development.

## Technologies

- Python
- Machine Learning
- Git
- GitHub
